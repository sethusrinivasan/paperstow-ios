# Privacy — Paperstow for iOS

Last updated: 2026-09-22

Paperstow keeps family travel papers on this iPhone. There is no Paperstow account and no Paperstow server.

## What stays on the device

Documents, tags, notes, checklists, and settings. Files are encrypted with AES-256-GCM. Unlock uses Face ID, Touch ID, or the device passcode.

## What may leave the device

- A file you share through the system share sheet
- A ZIP archive you export to Files
- Optional model or OS services Apple provides (for example Vision). Document bytes are not uploaded to a Paperstow backend

## Permissions (1.0)

- Camera — only if you scan a page
- Face ID — only to unlock

Location is not used in 1.0.
